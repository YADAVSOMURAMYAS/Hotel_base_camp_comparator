# ui

**Purpose:** small shared presentation pieces styled by the tokens in `../../styles/tokens.css`: `PillButton` (primary black / secondary white, optional orange arrow), `Card` (optional `accent`, `hover`), `Chip` (read-only) and `ChipToggle` (`aria-pressed` with a checkmark). Presentation only. `CountUp` counts the first display of an API number up from zero and always ends on exactly the string it was given. `PillButton` shows a press ripple. Tests: `ui.test.tsx`, `polish.test.tsx`.
